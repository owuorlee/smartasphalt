SMART ASPHALT WEBSITE
=====================
A plain static website: no server, no database. Open index.html in any browser to use it offline.

PUT IT ONLINE (so judges can open a link)
-----------------------------------------
Option A: GitHub Pages (free)
 1. Create a new repository on github.com (for example "smart-asphalt").
 2. Upload the CONTENTS of this folder (index.html, assets, media, ... ) to the repository root.
 3. Repository Settings > Pages > "Deploy from a branch" > main > / (root) > Save.
 4. After a minute your link is https://<your-username>.github.io/smart-asphalt/

Option B: Netlify Drop (free)
 1. Go to https://app.netlify.com/drop
 2. Drag this whole folder onto the page. You will probably need a free account to keep the site online.
 3. Netlify gives you a link; you can rename it in Site settings.

Option C: Cloudflare Pages (free) > Create project > Direct upload > drop the folder.

Then make a QR code for the link (any free QR generator) and put it on the poster and the last slide.

PRIVACY NOTES
-------------
 * The site tells search engines not to index it (noindex + robots.txt), so only people with the link will find it.
 * The Phase 4 full report contains your exact formulations. To withhold it, set PUBLISH_FORMULATIONS = False in build_site.py,
   run:  python build_site.py   and re-upload. The page will say "available on request".

UPDATING
--------
 * Pages are generated by build_site.py from the verified reports in ../../Road Research/Verified and the ledger in
   ../../Road Research/Verification (ledger_data.py). Edit those, then run:  python build_site.py
 * Replace media/Smart_Asphalt_Mechanism_Animation.mp4 to change the video. Add new videos on videos.html.

CHECKS RUN
----------
 * qa.py opens every page at desktop and phone width, checks for script errors, horizontal overflow and broken links.
